# API Reference

## Package modules

- `bluetooth_autoconnect.cli`
- `bluetooth_autoconnect.connector`
- `bluetooth_autoconnect.daemon`
- `bluetooth_autoconnect.dbus_client`
- `bluetooth_autoconnect.models`

These modules expose the CLI entry point, retry logic, BlueZ D-Bus wrapper, and configuration models used by the daemon.
